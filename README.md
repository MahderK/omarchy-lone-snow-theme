# Lone Snow

A cool, blue-toned night theme for [Omarchy](https://omarchy.org/), built around the Wallhaven "Lone Snow" wallpaper.

## Install

```bash
omarchy theme install https://github.com/MahderK/omarchy-lone-snow-theme
```

## Includes

- `colors.toml` — palette (terminals, editors, shell, and apps are themed from this)
- `icons.theme` — GTK icon theme
- `shell.lock.toml` — lock screen colors
- `unlock.png` / `preview-unlock.png` — Plymouth boot screen logo and preview
- `backgrounds/` — bundled wallpaper
